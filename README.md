# あさのじゅんびボード

小さな子どもの朝のしたくを、**時計の針の形**と**裏返すカード**で見せるボードです。
数字がまだ読めない子でも「時計がこの形になるまでに、これをやる」と分かるようにしています。

`index.html` 1ファイルだけで動きます。タブレット（Fire タブレットの Silk、iPad の Safari、Android の Chrome など）を壁に掛けて使う想定です。

公開ページ：https://nagisen.github.io/child_todo/

## できること

- まんなかの「いまの とけい」が本物の時刻で動く（スクロールしても上に小さく出続ける）
- やることごとに「この時間までに おわらせる」時刻を時計で表示し、いまやるカードに「いま」が付く
- カードをタップすると「できた！」に裏返る。日付が変わると自動で表に戻る
- 決めた時間帯（初期設定は 7:00〜9:00）だけ、時刻を過ぎても裏返していないカードが赤くなる
- しゅっぱつ欄のごほうびシールの丸をタップして貼る
- ページを開いている間は画面を消さない（対応ブラウザのみ。画面下に状態を表示）
- 「全画面」ボタンでブラウザのバーを隠す

## テレビの やくそくボード（`tv.html`）

テレビを見る「1日の回数」と「1回の時間」を、3歳の子にも見てわかるようにしたボードです（初期値は 3回・30分）。
朝のボードの下の「📺 テレビ」ボタンから開けます。

- 📺 カードが1回分のチケット。タップすると見はじめて、上の大きな丸のピンクが少しずつ減っていく
- 横の時計に「この とけいに なったら おしまい」の時刻を針で表示
- のこり5分で黄色の「もうすぐ おしまい」、0分で赤の「おしまい！ テレビ ばいばい」と音でお知らせ
- おしまいの音は「けしたよ」を押すまで6秒ごとにくり返す。画面下の「🔔 おとテスト」で前もって音を確かめられる
  - ブラウザの決まりで、ページを開いてから一度も画面をタップしていないと音は鳴らない（どこをタップしても準備できる）
- 見おわったカードは「みた！」に裏返る。ぜんぶ使うと「きょうの テレビは おしまい 🌙」
- 「ちょっと とめる」で一時停止、「おしまい にする」で早めに終わり（その回は使ったことになる）
- 回数と時間は画面下の「1日の回数」「1回の時間」で変えられる。日付が変わるとチケットが戻る

## 設定

ボード右下の「⚙ 設定（長押し）」を**長押し**すると設定画面が開きます（子どもが触って開かないように長押しにしています）。

| 項目 | 変えられること |
|---|---|
| ボード | タイトル、色（ピンク・そら・みどり・おひさま・シンプル）、うさぎの耳、マグネットの形 |
| やること | 絵文字または写真、名前（改行で2行）、時刻。追加・削除（10こまで） |
| しゅっぱつ | 絵文字、ことば、時刻 |
| カードの裏 | 絵文字、ことば |
| 時間の目印 | 「いま」を出しはじめる時刻、遅れを赤くするかどうかとその時間帯 |
| 時計の針の色 | みじかい針・ながい針の色（家の時計に貼るシールと合わせる） |
| ごほうびシール | 丸の数（7こまで）、下の文字、シールの絵文字、貼ったシールをぜんぶはがす |
| データ | 設定をファイルに書き出す・読み込む、はじめの設定に戻す |

写真は 240px 四方に切り抜いて小さくしてから保存します。

## データの保存場所

設定・裏返したカード・貼ったシールは、**そのブラウザの中（localStorage）だけ**に保存されます。サーバーには何も送りません。
別の端末に移すときは、設定画面の「ファイルに書き出す」「ファイルから読み込む」を使います。

## 自分用に公開する

1. このリポジトリをフォーク（またはコピー）する
2. Settings → Pages で Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

`index.html` を端末に保存して直接開いても動きます。画面を消さない機能は https で開いたときだけ動きます。

## Fire タブレットで使う

1. Silk ブラウザで公開ページを開き、ブックマークする
2. 長押しで設定を開き、やることと時刻を家の朝に合わせる
3. 「全画面」をタップしてブラウザのバーを隠す
4. 画面下が「画面スリープ：しない」になっていれば、開いている間は画面が消えません
   - 「端末の設定どおり」のときは、設定 → ディスプレイ → スリープ を長くするか、
     開発者オプションの「スリープモードにしない（充電中）」を使います
