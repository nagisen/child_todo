# child_todo

3歳の子の「あさの じゅんび」を、時計の針の形とやることカードで見せるボードです。
`index.html` 1ファイルだけで動きます（タブレットのブラウザ向け）。

## できること

- まんなかの「いまの とけい」が本物の時刻で動く（スクロールしても上に小さく出続ける）
- 上の段の時計は「この時間までに おわらせる」時刻。いまやるカードに「いま」が付く
- カードをタップすると「できた！」に裏返る。日付が変わると自動で表に戻る
- 7:00〜9:00 の間は、時刻を過ぎても裏返していないカードが赤くなる（「じかん すぎたよ」）
- しゅっぱつ欄のシールの丸をタップして貼る（げつ〜きん、1週間分残る）
- ページを開いている間は画面を消さない（対応ブラウザのみ。画面下に状態を表示）
- 「全画面」ボタンでブラウザのバーを隠す

カードとシールの状態は、そのブラウザの中にだけ保存されます。

## やることと時刻を変える

`index.html` の `STEPS`（やること・締め切り時刻・絵）と `GOAL`（しゅっぱつ時刻）を書き換えます。

## GitHub Pages で公開する

1. GitHub のリポジトリで Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/child_todo/` で開けるようになる

非公開リポジトリで Pages を使うには、有料プラン（GitHub Pro など）が必要です。
無料プランの場合は、リポジトリを公開（Settings → General → Change visibility）にする必要があります。
公開すると、URL を知っている人は誰でもページを見られます（中身は朝の予定だけです）。

## Fire タブレットで使う

1. Silk ブラウザで上の URL を開き、ブックマークする
2. 「全画面」をタップしてブラウザのバーを隠す
3. 画面下が「画面スリープ：しない」になっていれば、開いている間は画面が消えません
   - 「端末の設定どおり」のときは、設定 → ディスプレイ → スリープ を長くするか、
     開発者オプションの「スリープモードにしない（充電中）」を使います
